gridauto v0.4.0 — source-aware bounded positional solver

ТРЕБОВАНИЯ
- LuaLaTeX.
- Зависимости загружаются самим gridauto; нужен доступный пакет returntogrid.

УСТАНОВКА
Положите gridauto.sty рядом с главным .tex-файлом.

В преамбуле:
  \usepackage{gridauto}
  \GridAutoSetup{14pt}

ЛОКАЛЬНОЕ ОТКЛЮЧЕНИЕ
  {
    \GridAutoOff
    Текст без автоматической сеточной коррекции.
  }

или:
  \begin{gridautoff}
    Текст без автоматической сеточной коррекции.
  \end{gridautoff}

После закрытия группы/окружения настройки автоматически восстанавливаются.

СБОРКА
Рекомендуется:
  latexmk -lualatex main.tex

Для проверенных стандартных документов article/report v0.4.0 переставала выдавать предупреждение о
смене меток за 4–6 проходов. После очистки предупреждения все контрольные PDF сохраняли точное
пиксельное совпадение при дополнительном проходе.

ОГРАНИЧЕНИЯ
Это best-effort сеточная вёрстка, не замена выходного механизма TeX. Обычные figure/table принудительно
используют [H], чтобы избежать миграции через страницы. figure*/table* остаются плавающими; строгая
сетка вокруг них не гарантируется. Пользовательские классы, динамически меняющие .aux пакеты, библиография
и нестабильная пагинация могут потребовать дополнительных проходов. Предел итераций предотвращает бесконечный
цикл собственных поправок gridauto, но не может гарантировать конечное число проходов для абсолютно любого
произвольного LaTeX-документа.
