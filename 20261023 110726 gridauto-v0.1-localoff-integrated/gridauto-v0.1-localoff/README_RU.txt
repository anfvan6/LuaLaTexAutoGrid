gridauto v0.1 — локальное отключение автоматической сеточной вёрстки
====================================================================

Этот gridauto.sty основан на предоставленном исходнике v0.1. Добавлены два
способа локально отключать сеточную вёрстку. После выхода из группы или
окружения состояние автоматически восстанавливается средствами TeX-групп.

1. Отключение внутри группы
---------------------------

  {
    \GridAutoOff
    Здесь сеточная коррекция отключена.
    Можно использовать формулы, списки и заголовки без автоматического
    выравнивания по сетке.
  }

2. Отключение через окружение
-----------------------------

  \begin{gridautoff}
    Здесь сеточная коррекция отключена.
    Можно использовать формулы, списки и заголовки без автоматического
    выравнивания по сетке.
  \end{gridautoff}

Подключение
-----------

Положите gridauto.sty рядом с основным .tex:

  \usepackage{gridauto}
  \GridAutoSetup{14pt}

Компилируйте LuaLaTeX. Пакет требует returntogrid.

Что приостанавливается внутри области отключения
------------------------------------------------

* Принудительная установка GridStep в обработчике selectfont.
* Автоматическая коррекция \returntogrid при начале абзаца.
* Заданные пакетом интервалы вокруг display-формул и \jot для многострочных
  формул.
* Сеточные интервалы section/subsection/subsubsection, установленные titlesec.
* Нулевые интервалы enumitem, установленные gridauto.
* Принудительное размещение figure/table с [H]; восстанавливается штатный
  режим размещения floats.
* Локально возвращаются сохранённые исходные значения topskip, parskip,
  lineskip, параметров display math, caption skip и \@textbottom.

Ограничения
-----------

Это best-effort механизм, а не замена output routine TeX. Строгое выравнивание
всего содержимого, особенно плавающих figure*/table*, пользовательских блоков,
minipage и сложных вложенных окружений, не гарантируется. Если до входа в
область отключения уже была отложена коррекция после стандартного блока, она
сохраняется и может выполниться после выхода из области. Для фрагмента,
отключённого целиком, следующая базовая линия не обязательно будет точно
совпадать с глобальной сеткой, хотя шаг строк затем снова будет применяться.

--------

test.tex демонстрирует включённую сетку, display-формулы, отключение через
группу и через gridautoff, а также восстановление сетки после обеих областей.
Файл успешно компилируется LuaLaTeX. При сборке с чистыми вспомогательными
файлами предупреждение

без этого предупреждения; .aux оставался побайтно неизменным. Это результат
тестового документа, а не гарантия фиксированного числа проходов для любого
пользовательского документа.
