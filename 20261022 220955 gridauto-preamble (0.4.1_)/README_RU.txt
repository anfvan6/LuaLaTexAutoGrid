GridAuto — исправление v0.4.1 для многострочных заголовков
===========================================================

Эта версия сохраняет API и поведение v0.4 и устраняет лишние большие интервалы
МЕЖДУ строками длинных заголовков, набранных увеличенным шрифтом, например \Large.

Причина
-------
В v0.4 обработчик selectfont сравнивал размер шрифта с шагом сетки. Для
10-пунктового документа \Large обычно имеет размер 14.4 pt и естественный
межстрочный интервал 18 pt. При шаге сетки 14 pt прежний код ошибочно назначал
заголовку интервал 2*14=28 pt — из-за этого между строками заголовка выглядела
как будто вставлена пустая строка.

Исправление
-----------
Пакет теперь распознаёт локальную группу набора заголовка titlesec и сохраняет
естественный \baselineskip шрифта внутри заголовка. Поэтому \Large обычно остаётся
с интервалом 18 pt. В основном тексте после заголовка снова применяется шаг сетки,
заданный через \GridAutoSetup{...}. Команды документа и настройки отступов v0.4
не меняются.

Установка
---------
Замените старый gridauto.sty этим файлом и компилируйте документ LuaLaTeX.

    \usepackage{gridauto}
    \GridAutoSetup{14pt}

Существующие настройки заголовков остаются прежними:

    \GridAutoHeadingSpacing{section}{1}{1}
    \GridAutoHeadingSpacing{subsection}{2}{0}

Проверочный пример
------------------
Файл gridauto_large_heading_test.tex демонстрирует многострочные заголовки,
оформленные через \Large. Его можно собрать отдельно для проверки.

Ограничения
-----------
Исправление касается заголовков, набираемых механизмом titlesec. Пользовательские
команды заголовков, обходящие titlesec, требуют отдельной настройки. Это не
изменяет ограничения автоматической сеточной вёрстки v0.4 для плавающих объектов,
сносок и нестандартных окружений.
