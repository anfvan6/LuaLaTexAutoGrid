GridAuto — автоматическая коррекция базовой сетки (версия 0.6)

ИСПРАВЛЕНИЕ ВЕРСИИ 0.6
В версии 0.5 выключение уровня заголовка отключало коррекцию позиции и восстанавливало skips, но глобальный selectfont-hook всё ещё применял сеточный интерлиньяж к самому заголовку. В версии 0.6 hook временно отключается на время набора отключённого заголовка; после заголовка сеточная вёрстка основного текста продолжает работать. Для chapter добавлена отдельная обработка, поскольку глава открывает новую страницу.

СОВМЕСТИМОСТЬ
- Требуется LuaLaTeX.
- Рассчитан прежде всего на стандартные классы article, report и book.
- Шаг сетки по умолчанию: 14 pt.
- Для позиционных коррекций используется returntogrid; после изменения структуры документа или геометрии страницы может потребоваться несколько компиляций.

УСТАНОВКА
1. Положите gridauto.sty рядом с основным файлом .tex.
2. Подключите пакет ближе к концу преамбулы:
       \usepackage{gridauto}
       \GridAutoSetup{14pt}
3. Компилируйте LuaLaTeX повторно до стабилизации позиционных меток.
4. Для проверки временно используйте:
       \usepackage[debug]{gridauto}
   На страницах появится красная сетка. Уберите опцию debug в финальной версии.

НАСТРОЙКА ОТСТУПОВ ЗАГОЛОВКОВ
Все отступы задаются целым неотрицательным числом строк сетки. Ноль допустим отдельно сверху и снизу у каждого поддерживаемого уровня.

Команда с двумя независимыми значениями:
       \GridAutoHeadingSpacing{chapter}{4}{3}
       \GridAutoHeadingSpacing{section}{1}{1}
       \GridAutoHeadingSpacing{subsection}{2}{0}
       \GridAutoHeadingSpacing{subsubsection}{1}{1}
       \GridAutoHeadingSpacing{paragraph}{1}{0}
       \GridAutoHeadingSpacing{subparagraph}{0}{0}

Формат команды:
       \GridAutoHeadingSpacing{УРОВЕНЬ}{СТРОК_СВЕРХУ}{СТРОК_СНИЗУ}

Поддерживаемые уровни: chapter, section, subsection, subsubsection, paragraph, subparagraph.
Все значения кратны текущему \GridStep, который задаётся через \GridAutoSetup{...}.

Можно изменить верхний и нижний отступ раздельными командами, не меняя второе значение:
       \GridAutoHeadingBefore{section}{0}  % сверху 0 строк
       \GridAutoHeadingAfter{section}{2}   % снизу 2 строки

\GridAutoSetHeadingSpacing — синоним \GridAutoHeadingSpacing.

ОТКЛЮЧЕНИЕ СЕТКИ ДЛЯ ОТДЕЛЬНЫХ ВИДОВ ЗАГОЛОВКОВ
Можно отключить автоматическую сеточную обработку только для выбранного вида заголовка. Используйте квадратные скобки с именем уровня:
       \GridAutoOff[chapter]
       \GridAutoOff[section]
       \GridAutoOff[subsection]
       \GridAutoOff[subsubsection]
       \GridAutoOff[paragraph]
       \GridAutoOff[subparagraph]

Для выбранного уровня восстанавливаются исходные отступы titlesec/класса, автоматическое позиционное выравнивание пропускается, а сам заголовок набирается без принудительного шага GridStep (selectfont-hook временно отключён только на время построения заголовка). Основной текст после заголовка и остальные уровни продолжают использовать сетку. Для paragraph и subparagraph также возвращается исходный стиль заголовка (в стандартных классах — встроенный в строку).

Чтобы снова включить сеточную обработку уровня:
       \GridAutoOn[section]

Альтернативные команды без квадратных скобок:
       \GridAutoHeadingOff{section}
       \GridAutoHeadingOn{section}

Состояния переключателей локальны для группы. Поэтому отдельный вид заголовка можно отключать только на ограниченном фрагменте:
       {\GridAutoOff[subsection]
       \subsection{Заголовок без сеточной коррекции}
       }

Обычная команда \GridAutoOff без аргумента по-прежнему отключает всю сеточную вёрстку в текущей группе. Окружение gridautoff также сохраняет прежнее поведение:
       \begin{gridautoff}
       Весь механизм сетки временно выключен.
       \end{gridautoff}

ПРАВИЛО ДЛЯ СОСЕДНИХ ЗАГОЛОВКОВ
Когда один заголовок сразу следует за другим без обычного текста между ними, отступы не складываются. Используется только нижний отступ предыдущего заголовка; верхний отступ следующего заголовка в этой ситуации подавляется. Например, между section с нижним отступом 1 и subsection с верхним отступом 3 останется один шаг сетки, а не четыре. Если нужен больший интервал между такими заголовками, настройте нижний отступ предыдущего.

Для paragraph и subparagraph пакет использует блочные заголовки, чтобы отступ снизу был именно вертикальным. В стандартных классах LaTeX эти два вида заголовков обычно являются встроенными в строку (run-in), поэтому их вид меняется: текст после заголовка начинается со следующей строки. Внутри \GridAutoOff исходный стиль run-in восстанавливается локально.

Для chapter настройки применяются к стандартным определениям report/book с сохранением шрифта класса. У нестандартного класса или переопределённого макроса chapter эти патчи могут не подойти; в таком случае пакет выдаст предупреждение, и настройку нужно адаптировать под класс.

ЛОКАЛЬНОЕ ОТКЛЮЧЕНИЕ ВСЕЙ СЕТКИ
Группой:
       {\GridAutoOff
       Здесь сеточная коррекция отключена.
       }

Или окружением:
       \begin{gridautoff}
       Здесь сеточная коррекция отключена.
       \end{gridautoff}

\GridAutoDisable — синоним \GridAutoOff. Переключатель локален: после закрытия группы или окружения сетка снова включается. Не вызывайте \GridAutoOff без аргумента на верхнем уровне, если требуется отключить сетку только на небольшом участке.

ЧТО АВТОМАТИЗИРУЕТСЯ
- Шаг базовых линий стандартного текста.
- Настройка вертикальных интервалов заголовков, включая нулевые интервалы.
- Согласование соседних заголовков без сложения верхнего и нижнего отступов.
- Коррекция после стандартных display-формул, списков, quote/quotation, center/flushleft/flushright, figure и table.
- Обычные figure/table принудительно размещаются в исходном месте (аналог H), чтобы не перемещать плавающий объект на другую позицию страницы.

ОГРАНИЧЕНИЯ
Это автоматизированный best-effort механизм, а не универсальный движок, который гарантирует строгую сетку для любого LaTeX-источника. Плавающие figure*/table*, сноски, minipage/parbox, пользовательские окружения, произвольные box-структуры и нестандартные команды требуют отдельной проверки. В нестандартных классах нужно проверить поведение глав. Опция debug помогает обнаружить отклонения, но не гарантирует автоматическое исправление произвольных пользовательских конструкций.
