gridauto v0.4.1 — исправление Lua-синтаксической ошибки

ВАЖНО: пакет состоит из двух обязательных файлов:
  gridauto.sty
  gridauto-signature.lua
Положите оба файла рядом с главным .tex-файлом либо установите оба в один каталог,
доступный Kpathsea. Не копируйте только gridauto.sty: файл Lua содержит помощник
вычисления подписи исходников, необходимый для контроля итераций.

Подключение в преамбуле не меняется:
  \usepackage{gridauto}
  \GridAutoSetup{14pt}

Локальное отключение:
  {\GridAutoOff ... }
или:
  \begin{gridautoff} ... \end{gridautoff}

Компилировать с помощью LuaLaTeX. Для автоматических повторных проходов рекомендуется:
  latexmk -lualatex main.tex

Что исправлено в v0.4.1:
- Длинный Lua-скрипт вынесен из \directlua в отдельный gridauto-signature.lua.
  Это устраняет зависимость разбора Lua от токенизации TeX в большом встроенном блоке.
- Добавлена понятная ошибка, если вспомогательный Lua-файл отсутствует.
- Подпись включает исходник gridauto-signature.lua, чтобы изменение helper-кода сбрасывало
  состояние итераций.
- Публичные команды и алгоритм сеточной вёрстки v0.4.0 не изменены.

Результаты проверки
- Восемь контрольных сценариев собраны LuaLaTeX без ошибок.
- Предупреждение об изменении меток исчезло на 4–6-м проходах.
- В каждом случае выполнен дополнительный проход; предупреждение не вернулось.
- После редактирования включённого файла при сохранённом .aux предупреждение исчезло на 6-м проходе.
- Все восемь итоговых PDF после растеризации совпали пиксель в пиксель с исходными v0.4.0.

Ограничения
Это не даёт универсальной гарантии для любого возможного документа: другие пакеты,
библиография, пользовательские записи в .aux и меняющаяся пагинация могут вызывать свои
итерации. Результаты выше относятся к приложенным контрольным документам.
