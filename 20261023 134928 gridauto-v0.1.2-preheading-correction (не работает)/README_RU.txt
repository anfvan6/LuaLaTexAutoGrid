gridauto v0.1.2 — автоматическая коррекция фазы перед заголовком
=================================================================

Файл gridauto.sty основан на присланном пользователем v0.1 с локальными
командами отключения сетки. Версия v0.1.2 добавляет автоматическую
коррекцию вертикального отступа ПЕРЕД заголовком, чтобы первая строка
основного текста после заголовка попадала на базовую сетку.

Требования
----------
- LuaLaTeX
- пакет returntogrid
- пакеты titlesec, etoolbox, amsmath, enumitem, caption и float

Подключение
-----------
\usepackage{titlesec}
% Пользовательские настройки titlesec могут идти здесь.
\usepackage{gridauto}
\GridAutoSetup{14pt}

Что делает версия v0.1.2
------------------------
1. Считывает по данным предыдущей компиляции вертикальное положение первой
   строки текста после заголовка.
2. Вычисляет корректирующий отступ и вставляет его после штатного верхнего
   интервала titlesec, но перед самим заголовком. Это сделано потому, что
   добавление vspace до titlesec могло быть объединено с \addvspace.
3. Для стандартных форматов chapter обрабатывает как штатный формат класса,
   так и формат titlesec.
4. Если после заголовка текст начинается на следующей странице, сетка
   страницы начинается от \topskip. Если ранее применённый отступ вызвал
   перенос текста на следующую страницу, этот отступ сохраняется, чтобы
   исключить чередование между двумя вариантами пагинации.
5. Первый абзац после заголовка корректируется через отступ до заголовка;
   конкурирующая корректировка после блока для него не запускается.
6. Локальное отключение сетки сохранено:

   {\GridAutoOff
     Текст без автоматической сеточной коррекции.
   }

   \begin{gridautoff}
     Текст без автоматической сеточной коррекции.
   \end{gridautoff}

Проверка
--------
Тесты компилировались LuaLaTeX с опцией [debug], чтобы показывать красную
сетку. В test.tex предупреждение об изменении меток исчезло на 7-м проходе;
в localoff.tex — на 6-м; в near-page-break test — на 4-м. Это числа для этих
примеров, а не фиксированное число для любого документа.

Проверка фазы сетки выполнялась по сохранённой позиции первой строки тела:
в тестовых документах остаток (reference - topskip - body-position) по
модулю шага 14 pt равен 0 для каждого проверяемого тела заголовка после
стабилизации .aux.

Ограничения
-----------
Это автоматический best-effort механизм для стандартных классов article,
report и book. Как и у returntogrid, нестандартные классы, изменение числа
страниц, плавающие объекты, двухколоночный набор, собственные команды
заголовков, содержимое внутри minipage/box и особо сложные разрывы страниц
могут требовать дополнительной проверки. Компилируйте документ до исчезновения
предупреждения LaTeX о изменившихся метках; для автоматизации подойдёт latexmk.
